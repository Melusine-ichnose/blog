## 项目简介

功能完善的 B2B2C 多商户商城系统，采用前后端分离架构。后端基于 SpringBoot 构建，支持分布式部署；前端覆盖 PC、H5、小程序和 APP，基于 Vue 和 uni-app 开发。

## 技术栈

- 后端：Spring Boot、MyBatis-Plus、MySQL、RocketMQ、Redis、MongoDB、Elasticsearch、Spring Security、ShardingSphere、XXL-Job、JWT
- 管理端：Vue.js、iView、Vuex、Vue Router、axios
- 移动端：uni-app、uViewUI、SCSS

## 核心特性

- 全端覆盖：一套代码库支持 PC、H5、小程序、APP
- 商家入驻：支持多商家入驻，构建平台化电商生态
- 分布式架构：后端 API 服务化，支持独立部署和弹性伸缩
- 容器化支持：提供 Docker 镜像和 docker-compose 配置
